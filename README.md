# 💻 Calculator

## 🗙️ Overview
A simple calculator application implemented in Java. This program provides basic arithmetic operations and a graphical user interface for user-friendly interaction.

## 🚀 Features
- **Basic Arithmetic Operations**: Perform addition, subtraction, multiplication, and division.
- **Graphical User Interface (GUI)**: Intuitive and user-friendly interface for easy calculations.
- **Error Handling**: Displays error messages for invalid operations, such as division by zero.

## 🛠️ Installation and Setup
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/parisppdo/Calculator.git
   ```
2. **Navigate to the Project Directory**:
   ```bash
   cd Calculator/src  # Navigate to the source directory
   ```
3. **Compile the Application**:
   ```bash
   javac Calc.java
   ```
4. **Run the Application**:
   ```bash
   java Calc
   ```

## 📋 How to Use
1. **Launch the Application**: Run the program as described above.
2. **Perform Calculations**:
    - Enter numbers using the provided buttons.
    - Select the desired arithmetic operation.
    - Press the equals (`=`) button to view the result.
    - Use the clear (`C`) button to reset the input.
    - Use the Delete (`DEL`) button to delete the input.
